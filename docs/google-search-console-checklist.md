# Google Search Console Checklist

Date: 2026-08-16

Search Console is not connected to this repository. Do not claim it was checked unless the account is actually opened.

## After Merge And Production Deployment

- Open the `https://ki-packt-an.de/` property.
- Confirm the property is verified.
- Submit or resubmit `https://ki-packt-an.de/sitemap.xml`.
- Check sitemap status and discovered URL count.
- Use URL Inspection for:
  - `https://ki-packt-an.de/`
  - `https://ki-packt-an.de/openclaw-fuer-unternehmen/`
  - `https://ki-packt-an.de/wissen/produktive-ki-agenten-openclaw-mittelstand/`
  - `https://ki-packt-an.de/wissen/openclaw-sicher-betreiben/`
  - `https://ki-packt-an.de/wissen/prompt-injection-test-ki-agent-email/`
- Request indexing for newly published cornerstone and research pages where appropriate.
- Check Google-selected canonical matches the submitted canonical.
- Check crawl status, fetch status and rendered HTML.
- Review Page indexing for noindex, duplicate or alternate canonical problems.
- Review Mobile Usability and Core Web Vitals.
- Review Manual Actions.
- Review Security Issues.
- Review search queries, impressions, clicks and CTR after data starts accumulating.

## External Validators

- Google Rich Results Test for representative pages.
- Schema.org Validator for JSON-LD.
- PageSpeed Insights for mobile and desktop Core Web Vitals field/lab signals.
